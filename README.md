# ⚡ Yomate | Deep Work Forge

**A high-performance environment for students, coders, and builders to master their time and focus.**

`Yomate` is more than a productivity app; it's a protocol-driven workspace designed to eliminate distraction and facilitate deep, cognitive-intensive work. Built for those who treat their study and coding sessions as a high-performance craft.

---

## 🏗️ Core Pillars

### 1. The Focus Hub
- **Deep Work Mode:** Intense sessions with integrated ambient soundscapes (Rain, Forest, Campfire, etc.) and zen-mode visuals.
- **Pomodoro Protocol:** Dynamic phase switching (Work, Short Break, Long Break) with automatic cycling.
- **Distraction Restraint:** Active "Device Check" system to ensure your environment is secure before you begin.

### 2. Mission Protocol
- **Smart Timetable:** An adaptive schedule that centers on your current block, providing a clear "Up Next" preview and sleep countdowns.
- **Daily Rituals:** Non-negotiable habits to anchor your performance (Gym, Journaling, Hydration).
- **Subject Strategy:** Assign specific subjects to Study Blocks to maintain a balanced mastery curriculum.

### 3. Cognitive Engine
- **Brain Dump:** Capture intrusive thoughts instantly during focus sessions without losing momentum.
- **System Efficiency:** Real-time tracking of "Time Earned" through efficient session execution.
- **The Horizon:** Visual deadline tracking to keep your long-term targets in sight.

---

## 🎨 Premium Aesthetics
- **Adaptive Themes:** Soft Dark (Zinc), OLED Black, and Clean Light modes.
- **Dynamic Accents:** Personalize your forge with Indigo, Emerald, Rose, Violet, or Orange.
- **Haptic Excellence:** Native-feeling feedback for tactile interactions.
- **Glassmorphic UI:** Modern, blurred interfaces that prioritize information density.

---

## 🛠️ Tech Stack
- **Frontend:** React 18, TypeScript, Tailwind CSS
- **Icons:** Lucide React
- **Audio:** Tone.js (Generative soundscapes)
- **State & Storage:** Local Persistence with automated state hydration.
- **PWA:** Service Worker integration for offline capability and native install experience.

---

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (Latest LTS)
- [pnpm](https://pnpm.io/) (Recommended)

### Installation
1. Clone the repository
2. Install dependencies:
   ```bash
   pnpm install
   ```
3. Run the development server:
   ```bash
   pnpm dev
   ```

---

## 📱 Mobile Installation
`Yomate` is a Progressive Web App (PWA).
- **iOS:** Open in Safari -> Share -> Add to Home Screen.
- **Android/Chrome:** Click the "Install" prompt or "Add to Home Screen" in settings.
